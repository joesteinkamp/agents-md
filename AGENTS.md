## Agent Rule Directory (`.agents/`)
Context-specific guidance is organized within the `.agents/` directory. When working in this repository, consult the following subdirectories:
* `.agents/rules/` - Domain-specific rules and conventions to follow when editing code (e.g., frontend, backend, or testing guidelines).
* `.agents/skills/` - Actionable skills and workflows to execute specific tasks (e.g., automated commit and merge sequences).
